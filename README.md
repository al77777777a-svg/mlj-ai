# 🎙️ بوت ديسكورد صوتي بالذكاء الاصطناعي

بوت يدش الروم الصوتي في سيرفرك، يسمع اللي يكلمه، ويرد عليه **بصوت**. العقل حقه **Claude**.

```
صوتك ← تحويل لنص (Groq Whisper) ← Claude يفكر ويرد ← تحويل لصوت (Groq / Azure / ElevenLabs) ← يتكلم في الروم
```

- يفهم عربي (خليجي/إماراتي) وإنجليزي، ويرد بنفس لغتك.
- يرد لما تناديه باسمه («يا كلود …»)، أو على أي كلام إذا تبي.
- يتذكر السالفة، فتقدر تسأله سؤال ورا سؤال.
- توقفه بكلمة «اسكت» أو «خلاص» وهو يتكلم.

---

## اللي تحتاجه (3 مفاتيح)

| المفتاح | من وين | ملاحظة |
|---|---|---|
| `DISCORD_TOKEN` | https://discord.com/developers/applications | New Application ← Bot ← Reset Token |
| `ANTHROPIC_API_KEY` | https://platform.claude.com | يحتاج رصيد API (اشتراك claude.ai شي ثاني) |
| `GROQ_API_KEY` | https://console.groq.com/keys | فيه خطة مجانية — للسمع والصوت |

## الطريقة 1: Railway (عن طريق GitHub)

**1) ارفع الملفات على GitHub**
1. في GitHub سوّ **New repository** (الأفضل Private).
2. اضغط **uploading an existing file** (أو Add file ← Upload files).
3. اسحب **كل ملفات البوت مرة وحدة** وبعدين **Commit changes**.

> ⚠️ لا ترفع `node_modules` ولا ملف `.env` (فيه مفاتيحك).

**2) شغّله في Railway**
1. **New Project** ← **Deploy from GitHub repo** ← اختر الريبو.
2. افتح الخدمة ← **Variables** ← **Raw Editor**، والصق هذا بعد ما تحط مفاتيحك:
   ```
   DISCORD_TOKEN=حط_التوكن_هنا
   ANTHROPIC_API_KEY=حط_مفتاح_Claude_هنا
   GROQ_API_KEY=حط_مفتاح_Groq_هنا
   ```
   (باقي الإعدادات في `.env.example` اختيارية — تقدر تضيفها بنفس الطريقة.)
3. اضغط **Update Variables** و Railway يعيد التشغيل.
4. افتح **Deployments** ← **View Logs**: بتلقى **رابط إضافة البوت** — افتحه واختر سيرفرك.
5. ادخل روم صوتي واكتب `/join` 🎧

> **تنبيه:** في تقارير حديثة إن الاتصال الصوتي حق ديسكورد (UDP) يعلق على Railway. إذا `/join` قال «الاتصال الصوتي ما اكتمل»: جرّب تغيّر المنطقة (Settings ← Region)، وإذا ما نفع شغّله على جهازك (الطريقة 2) أو على VPS.

---

## الطريقة 2: على جهازك

1. ثبّت **Node.js 24 LTS** من https://nodejs.org
2. حط ملفات البوت في مجلد، وانسخ `.env.example` باسم `.env`، وعبّي فيه المفاتيح الثلاثة.
3. افتح Terminal داخل المجلد:
   ```bash
   npm install
   npm run check
   npm start
   ```
   `npm run check` يجرب المفاتيح بدون ديسكورد، ويحفظ عينة من صوت البوت في `voice-test.wav` تسمعها.
4. افتح رابط إضافة البوت اللي يطلع في الكونسول، وادخل روم صوتي واكتب `/join`.

البوت يشتغل بس وجهازك شغال.

## طريقة الاستخدام

**بالصوت**
- «يا كلود» + سؤالك ← يرد بصوت.
- «يا كلود» بروحها ← يقول «سم» وتكمل سؤالك.
- بعد ما يرد عليك، عندك 15 ثانية تكمل السالفة بدون ما تناديه.
- «اسكت» / «خلاص» / «كلود وقف» ← يوقف كلامه.

**الأوامر**

| الأمر | وش يسوي |
|---|---|
| `/join` | يدش الروم الصوتي اللي أنت فيه |
| `/leave` | يطلع من الروم |
| `/ask` | تسأله كتابة، ويرد كتابة (وبصوت إذا هو في الروم) |
| `/mode` | يرد بس لما تناديه، أو على أي كلام |
| `/stop` | يسكت ويلغي الردود اللي بالانتظار |
| `/reset` | ينسى السالفة ويبدأ من جديد |

## إعدادات اختيارية

| الإعداد | الافتراضي | وش يغيّر |
|---|---|---|
| `BOT_NAME` | كلود | اسم البوت (ينتبه له تلقائياً) |
| `WAKE_WORDS` | كلود,كلاود,claude,بوت | أسماء ثانية ينتبه لها |
| `REPLY_MODE` | `name` | `everyone` = يرد على أي كلام |
| `TTS_PROVIDER` | `groq` | `azure` لأصوات إماراتية (حمدان/فاطمة)، `elevenlabs` لأصوات طبيعية جداً |
| `GROQ_VOICE_AR` | `sultan` | أصوات ثانية: fahad, abdullah, noura, lulwa, aisha |
| `ANTHROPIC_MODEL` | `claude-haiku-5-5` | `claude-sonnet-5-5` أذكى بس أبطأ شوي |
| `WEB_SEARCH` | `false` | `true` = يبحث في النت للأخبار والطقس |
| `AUTO_JOIN_CHANNEL_ID` | فاضي | آيدي روم يدشه البوت تلقائياً ويبقى فيه |
| `POST_TRANSCRIPTS` | `true` | يكتب السؤال والجواب في شات الروم |

كل الإعدادات مشروحة في `.env.example`. **شخصية البوت** (طريقة كلامه ولهجته) في ملف `prompt.txt`.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| أوامر `/` ما تطلع | أضف البوت مرة ثانية بالرابط اللي في الـ Logs، وسكّر ديسكورد وافتحه. |
| «الاتصال الصوتي ما اكتمل» | الاستضافة تمنع UDP. جرّب منطقة ثانية أو جهاز ثاني. خلي `DEBUG=true` للتفاصيل. |
| يدش بس ما يسمع | تأكد إنه مو **Server Deafen**، وشوف الـ Logs: لازم يطلع فيها كلامك 🗣️. |
| يسمع بس ما يتكلم | شوف رسالة الخطأ في شات الروم أو الـ Logs. إذا Groq طلب الموافقة على الشروط (terms)، افتح الموديل في Groq Playground ووافق. |
| يرد على كلام مو له | خله `REPLY_MODE=name` وقلّل `FOLLOWUP_SECONDS`. |
| خطأ 401 أو رصيد | تأكد من المفاتيح ومن رصيد حساب Claude API. |

## الخصوصية

- لما البوت يدش يكتب في الشات إنه يسمع — خبّر ربعك إن البوت في الروم.
- الصوت ما ينحفظ: يتحول لنص عند الخدمة اللي اخترتها (Groq/OpenAI)، والنص يروح لـ Claude عشان الرد.
