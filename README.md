# 🎙️ بوت ديسكورد صوتي بالذكاء الاصطناعي (كله على Groq)

بوت يدش الروم الصوتي في سيرفرك، يسمع اللي يكلمه، ويرد عليه **بصوت**.
يحتاج **مفتاحين بس**: توكن ديسكورد، ومفتاح Groq المجاني.

```
صوتك ← تحويل لنص (Groq Whisper) ← الذكاء الاصطناعي (Groq gpt-oss) ← تحويل لصوت (Groq) ← يتكلم في الروم
```

- يفهم عربي (خليجي/إماراتي) وإنجليزي، ويرد بنفس لغتك.
- يرد لما تناديه باسمه («يا بوت …»)، أو على أي كلام إذا تبي.
- يتذكر السالفة، فتقدر تسأله سؤال ورا سؤال.
- توقفه بكلمة «اسكت» أو «خلاص» وهو يتكلم.

## المفتاحين

| المفتاح | من وين |
|---|---|
| `DISCORD_TOKEN` | https://discord.com/developers/applications ← تطبيقك ← Bot ← Reset Token |
| `GROQ_API_KEY` | https://console.groq.com/keys ← Create API Key (مجاني، بدون بطاقة) |

---

## الطريقة 1: Railway (عن طريق GitHub)

**1) ارفع الملفات على GitHub**
1. افتح الريبو حقك في GitHub ← **Add file** ← **Upload files**.
2. اسحب **كل ملفات البوت مرة وحدة** — الملفات اللي بنفس الاسم تتبدل بالجديدة.
3. اضغط **Commit changes**.

> ⚠️ لا ترفع `node_modules` ولا ملف `.env` (فيه مفاتيحك).

**2) شغّله في Railway**
1. **New Project** ← **Deploy from GitHub repo** ← اختر الريبو (إذا ما سويته من قبل).
2. افتح الخدمة ← **Variables** ← **Raw Editor**، وتأكد إن فيها هذول الاثنين:
   ```
   DISCORD_TOKEN=حط_التوكن_هنا
   GROQ_API_KEY=حط_مفتاح_Groq_هنا
   ```
3. Railway يعيد التشغيل بروحه. افتح **Deployments** ← **View Logs**: بتلقى **رابط إضافة البوت** — افتحه واختر سيرفرك.
4. ادخل روم صوتي واكتب `/join` 🎧

> **تنبيه:** في تقارير إن الاتصال الصوتي حق ديسكورد (UDP) يعلق على Railway. إذا `/join` قال «الاتصال الصوتي ما اكتمل»: جرّب تغيّر المنطقة (Settings ← Region)، وإذا ما نفع شغّله على جهازك (الطريقة 2).

---

## الطريقة 2: على جهازك

1. ثبّت **Node.js 24 LTS** من https://nodejs.org
2. حط ملفات البوت في مجلد، وانسخ `.env.example` باسم `.env`، وعبّي فيه المفتاحين.
3. افتح Terminal داخل المجلد:
   ```bash
   npm install
   npm run check
   npm start
   ```
   `npm run check` يجرب المفتاح بدون ديسكورد، ويحفظ عينة من صوت البوت في `voice-test.wav` تسمعها.
4. افتح رابط إضافة البوت اللي يطلع، وادخل روم صوتي واكتب `/join`.

## طريقة الاستخدام

**بالصوت**
- «يا بوت» + سؤالك ← يرد بصوت.
- «يا بوت» بروحها ← يقول «سم» وتكمل سؤالك.
- بعد ما يرد عليك، عندك 15 ثانية تكمل السالفة بدون ما تناديه.
- «اسكت» / «خلاص» / «بوت وقف» ← يوقف كلامه.

تبي اسم ثاني؟ حط `BOT_NAME` في Variables (مثلاً `BOT_NAME=سالم`) وناديه بالاسم الجديد.

**الأوامر**

| الأمر | وش يسوي |
|---|---|
| `/join` | يدش الروم الصوتي اللي أنت فيه |
| `/leave` | يطلع من الروم |
| `/ask` | تسأله كتابة، ويرد كتابة (وبصوت إذا هو في الروم) |
| `/mode` | يرد بس لما تناديه، أو على أي كلام |
| `/stop` | يسكت ويلغي الردود اللي بالانتظار |
| `/reset` | ينسى السالفة ويبدأ من جديد |

## حدود Groq المجانية

Groq مجاني بس له حد يومي لكل جزء. **أول شي يخلص عادة هو الصوت العربي** (حوالي 100 طلب صوت في اليوم).
لما يخلص:
- البوت يكتب في شات الروم «وصلنا حد Groq المجاني»، والجواب يظل مكتوب في الشات.
- الحد يرجع لحاله اليوم الثاني.
- تبي أكثر؟ فعّل الدفع في Groq (رخيص)، أو غيّر الصوت لـ Azure (`TTS_PROVIDER=azure`، فيه خطة مجانية أكبر).

نصيحة: خله يرد بس لما تناديه (`REPLY_MODE=name`) عشان ما يصرف الحد على كلام مو له.

## إعدادات اختيارية

| الإعداد | الافتراضي | وش يغيّر |
|---|---|---|
| `BOT_NAME` | بوت | اسم البوت (ينتبه له تلقائياً) |
| `WAKE_WORDS` | بوت,bot | أسماء ثانية ينتبه لها |
| `REPLY_MODE` | `name` | `everyone` = يرد على أي كلام |
| `GROQ_CHAT_MODEL` | `openai/gpt-oss-120b` | `openai/gpt-oss-20b` أسرع |
| `GROQ_VOICE_AR` | `sultan` | أصوات ثانية: fahad, abdullah, noura, lulwa, aisha |
| `TTS_PROVIDER` | `groq` | `azure` لأصوات إماراتية (حمدان/فاطمة) |
| `AUTO_JOIN_CHANNEL_ID` | فاضي | آيدي روم يدشه البوت تلقائياً ويبقى فيه |
| `POST_TRANSCRIPTS` | `true` | يكتب السؤال والجواب في شات الروم |

كل الإعدادات مشروحة في `.env.example`. **شخصية البوت** (طريقة كلامه ولهجته) في ملف `prompt.txt`.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| أوامر `/` ما تطلع | أضف البوت مرة ثانية بالرابط اللي في الـ Logs، وسكّر ديسكورد وافتحه. |
| «الاتصال الصوتي ما اكتمل» | الاستضافة تمنع UDP. جرّب منطقة ثانية أو جهاز ثاني. خلي `DEBUG=true` للتفاصيل. |
| يدش بس ما يسمع | تأكد إنه مو **Server Deafen**، وشوف الـ Logs: لازم يطلع فيها كلامك 🗣️. |
| «وصلنا حد Groq المجاني» | خلص الحد اليومي — يرجع بكرة. |
| يرد على كلام مو له | خله `REPLY_MODE=name` وقلّل `FOLLOWUP_SECONDS`. |
| خطأ 401 | مفتاح Groq غلط — سو مفتاح جديد وحطه في Variables. |

## الخصوصية

- لما البوت يدش يكتب في الشات إنه يسمع — خبّر ربعك إن البوت في الروم.
- الصوت ما ينحفظ: يتحول لنص عند Groq، والنص يروح للذكاء الاصطناعي في Groq عشان الرد.
