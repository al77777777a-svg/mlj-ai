# 🎙️ فطوم — بوت ديسكورد صوتي بلهجة إماراتية

بوت يدش الروم الصوتي في سيرفرك، يسمع اللي يكلمه، ويرد عليه **بصوت بنت إماراتية**.
**Gemini** هو عقلها وصوتها، و**Groq** يسمعك (تحويل الصوت لنص) ويظل **احتياط** إذا خلص حد Gemini.

```
صوتك ← Groq Whisper (نص) ← Gemini (الرد) ← Gemini (صوت إماراتي) ← يتكلم في الروم
                                  └─ إذا خلص الحد: Groq يرد ويتكلم بداله
```

- تتكلم **عربي إماراتي بس**، حتى لو كلمتها بالإنجليزي.
- اسمها **فطوم**: ناديها «فطوم» وبروحها، تقول لك «ها حياتي» (أو «هلا ابوي تفضل»، «ها عيوني شي؟»).
- ترد لما تناديها باسمها (حتى «فطومي» و«فطوماتي»)، وبعد ما ترد عليك تكمل السالفة بدون نداء.
- يتذكر السالفة، فتقدر تسأله سؤال ورا سؤال.
- **تكمل كلامها** حتى لو أحد تكلم فوقها. توقفها «فطوم اسكتي» أو «اسكتي»، أو «بس» من اللي تكلمه.

## المفاتيح

| المفتاح | من وين |
|---|---|
| `DISCORD_TOKEN` | https://discord.com/developers/applications ← تطبيقك ← Bot ← Reset Token |
| `GROQ_API_KEY` | https://console.groq.com/keys ← Create API Key (مجاني، بدون بطاقة) |
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey ← Create API key (عقلها وصوتها) |
| `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` | https://portal.azure.com ← Create a resource ← **Speech** ← Pricing tier **Free F0** ← Keys and Endpoint (**ننصح فيه**: أوضح وأسرع صوت إماراتي، وحده المجاني الشهري كبير) |
| `CEREBRAS_API_KEY` | https://cloud.cerebras.ai (عقل احتياط سريع، مجاني) |
| `OPENROUTER_API_KEY` | https://openrouter.ai/keys (عقل احتياط، الافتراضي `openrouter/free` يختار موديل مجاني شغال) |
| `MISTRAL_API_KEY` | https://console.mistral.ai (عقل احتياط، مجاني، يحتاج تحقق برقم الجوال) |
| `SAMBANOVA_API_KEY` | https://cloud.sambanova.ai (عقل احتياط) |
| `CUSTOM_LLM_URL` / `CUSTOM_LLM_API_KEY` / `CUSTOM_LLM_MODEL` | أي خدمة ثانية بصيغة OpenAI |

بدون `GEMINI_API_KEY` البوت يشتغل كله على Groq (أقل جودة، وحدوده أصغر).

**العقول:** Groq وGemini يحسبون الحد المجاني **لكل موديل**، فمن مفتاح Groq ومفتاح Gemini تطلع عدة عقول، كل واحد بحده:

| العقل | الموديل | المفتاح |
|---|---|---|
| `gemini` | `gemini-3.5-flash-lite` (سريع، حوالي 500 طلب باليوم) | Gemini |
| `groq` | `openai/gpt-oss-120b` | Groq |
| `geminilite` | `gemini-3.1-flash-lite` | Gemini |
| `groq20b` | `openai/gpt-oss-20b` | Groq |
| `groqqwen` | `qwen/qwen3.8-27b` | Groq |
| `geminiflash` | `gemini-3.6-flash` | Gemini |
| `gemini38` | `gemini-3.8-flash` (20 طلب باليوم بس، فهو آخر واحد) | Gemini |
| `mistral` / `openrouter` / `cerebras` / `sambanova` / `custom` | موديل كل خدمة | مفتاحها |

- **الصوت** يسأل بالترتيب: gemini ← groq ← geminilite ← groq20b ← groqqwen ← mistral ← geminiflash ← cerebras ← openrouter ← sambanova ← gemini38.
- **الشات المكتوب** يسأل بترتيب ثاني (geminilite ← geminiflash ← groqqwen ← mistral ← …)، عشان الشات ما يخلص حدود الصوت.
- إذا عقل وقف أو خلص حده أو تأخر أكثر من `LLM_HEDGE_MS`، اللي بعده يرد وأول جواب يربح، والمتعطل يرتاح (لين الوقت اللي تقوله الخدمة). الموديل اللي انحذف يرتاح 12 ساعة.
- إذا كلهم مرتاحين، تجرب بس الاثنين اللي يصحون أول (مب كلهم، عشان ما تتأخر).
- البحث في Google (أخبار، طقس…) يروح لـ Gemini أول. `<NAME>_CHAT_MODEL=none` يطفي أي عقل، و`LLM_PROVIDER`/`LLM_FALLBACK` تحط ترتيبك أنت.

## الطريقة 1: Railway (عن طريق GitHub)

**1) ارفع الملفات على GitHub**
1. افتح الريبو حقك في GitHub ← **Add file** ← **Upload files**.
2. اسحب **كل ملفات البوت مرة وحدة** — الملفات اللي بنفس الاسم تتبدل بالجديدة.
3. اضغط **Commit changes**.

> ⚠️ لا ترفع `node_modules` ولا ملف `.env` (فيه مفاتيحك).

**2) شغّله في Railway**
1. **New Project** ← **Deploy from GitHub repo** ← اختر الريبو (إذا ما سويته من قبل).
2. افتح الخدمة ← **Variables** ← **Raw Editor**، وتأكد إن فيها هذول الثلاثة:
   ```
   DISCORD_TOKEN=حط_التوكن_هنا
   GROQ_API_KEY=حط_مفتاح_Groq_هنا
   GEMINI_API_KEY=حط_مفتاح_Gemini_هنا
   ```
   وبعد أي تغيير في Variables اضغط **Deploy**.
3. Railway يعيد التشغيل بروحه. افتح **Deployments** ← **View Logs**: بتلقى **رابط إضافة البوت** — افتحه واختر سيرفرك.
4. ادخل روم صوتي واكتب `/join` 🎧

> **تنبيه:** في تقارير إن الاتصال الصوتي حق ديسكورد (UDP) يعلق على Railway. إذا `/join` قال «الاتصال الصوتي ما اكتمل»: جرّب تغيّر المنطقة (Settings ← Region)، وإذا ما نفع شغّله على جهازك (الطريقة 2).

---

## الطريقة 2: على جهازك

1. ثبّت **Node.js 24 LTS** من https://nodejs.org
2. حط ملفات البوت في مجلد، وانسخ `.env.example` باسم `.env`، وعبّي فيه المفاتيح.
3. افتح Terminal داخل المجلد:
   ```bash
   npm install
   npm run check
   npm start
   ```
   `npm run check` يجرب المفتاح بدون ديسكورد، ويحفظ عينة من صوت البوت في `voice-test.wav` تسمعها.
4. افتح رابط إضافة البوت اللي يطلع، وادخل روم صوتي واكتب `/join`.

## طريقة الاستخدام

**بالصوت**
- «فطوم» + سؤالك ← ترد بصوت.
- «فطوم» بروحها ← تقول «ها حياتي» وتكمل سؤالك.
- اسمها مع نهاية («فطومي»، «فطومتي»، «فطوماتي») يناديها بعد.
- «السلام عليكم» ← ترد فوراً «وعليكم السلام» بدون ما تفكر، في أي روم: مرة لكل واحد كل 10 دقايق (`SALAM_COOLDOWN_SECONDS`)، ورد واحد إذا سلموا مع بعض.
- بعد ما ترد عليك: في الروم الصغير (شخصين أو أقل) عندك 15 ثانية تكمل بدون ما تناديها، وفي الروم الزحمة عندك 10 ثواني لسؤال ثاني (`FOLLOWUP_BIG_SECONDS`).
- **ما تسكت إذا أحد تكلم فوقها** (`BARGE_IN=false` الافتراضي): تكمل جملتها. توقفها:
  - «فطوم اسكتي» / «فطوم خلاص» / «اسكتي» / «وقفي» من أي واحد،
  - «بس» / «خلاص» من اللي تكلمه هي (أو في الروم الصغير).
  - «بس» و«خلاص» بين الناس الثانيين في الروم الزحمة ما توقفها.
- إذا سؤال انتظر أكثر من 40 ثانية (كانت مشغولة)، تتركه بدل ما ترد متأخر (`STALE_SECONDS`).
- **ترحيب**: إذا أحد دخل الروم تقول «هلا والله {اسمه}». `WELCOME=false` يطفيه.
- **التنقل بين الرومات**: «فطوم روحي روم القهوة» ← تقول تمام وتروح. لازم تنادي اسمها، وتحتاج صلاحية الدخول في الروم الثاني (View Channel + Connect + Speak). `MOVE_BY_VOICE=false` يطفيه.
- **معلومات حديثة**: أخبار، طقس، أسعار، نتايج مباريات، مواقيت صلاة. تبحث في جوجل عن طريق Gemini لما السؤال يحتاج، وتجاوب باختصار. `WEB_SEARCH=off` يطفيها، و`always` تبحث دايماً (أبطأ).

تبي اسم ثاني؟ حط `BOT_NAME` في Variables (مثلاً `BOT_NAME=مريم`) وناديها بالاسم الجديد.

**الصورة والاسم:** ديسكورد ما يسمح للبوتات بفتح كاميرا، فبدالها البوت يحط **صورة بروفايل** (`avatar.png`) واسمه «فطوم» في السيرفر.
تبي صورتك؟ بدّل `avatar.png` وحط `BOT_AVATAR_UPDATE=true` مرة وحدة.

**بالكتابة (الشات العام)**
- فطوم تسولف كتابة في روم الشات اللي تحدده (`TEXT_CHANNEL_IDS`، الافتراضي الشات العام)، بنفس لهجتها وخفة دمها، وبنفس ذاكرة الناس والسيرفر.
- متى ترد؟ `TEXT_REPLY_MODE`: `questions` (الافتراضي: إذا ناديتها، أو سؤال مفتوح للكل من 3 كلمات وأكثر — مرة كل `TEXT_COOLDOWN_SECONDS`=90 ثانية)، `name` (بس إذا ناديتها أو منشنتها أو رديت عليها)، `everyone` (على كل شي).
- بعد ما ترد عليك، تقدر تسألها سؤال ثاني بدون اسمها خلال `TEXT_FOLLOWUP_SECONDS`=20 ثانية، وسؤالين ورا بعض بالكثير (`TEXT_FOLLOWUPS_IN_A_ROW`=2). «ههههه» و«امبيه» ما ترد عليها، عشان ما ترد على كل سطر في الشات.
- ما تتدخل بين اثنين يسولفون مع بعض (منشن أو رد على غيرها)، وما تبدا ردها باسم الشخص.
- **تحفظ الشات**: منو يسولف وكم رسالة هالأسبوع، ومنو اختفى (`QUIET_DAYS`، الافتراضي 3 أيام)، وآخر الكلام عشان تفهم جو الشلة وتسولف بأسلوبهم. الروابط والأرقام الطويلة (جوالات، حسابات) ما تنحفظ. `/forget` يمسح كل شي.
- **حسون (أو أي بوت ثاني)**: أسماؤهم في `FRIEND_BOTS`. ترد على البوت بس إذا هو ناداها أو منشنها أو رد عليها، وأقصى `TEXT_BOT_CHAIN_MAX` ردود ورا بعض، وأي رسالة من إنسان تفصل السلسلة. «فطوم كلمي حسون» تبدأ معه سالفة.
- **لازم تفعّل Message Content Intent** (مرة وحدة): Discord Developer Portal ← تطبيق البوت ← Bot ← Privileged Gateway Intents ← **Message Content Intent** ← Save. بدونها يشتغل الصوت بس، وفي الـ Logs يطلع سطر يقولك وش تسوي. `TEXT_CHANNEL_IDS=none` يطفي الكتابة.

**الذاكرة**
- فطوم تعرف **منو في الروم** الحين (تقدر تقول لها «منو معاي؟»)، وتتذكر اللي تقوله لها عن نفسك وعن السيرفر (اسمك، شغلك، اللي تحبه…) وتستخدمه في كلامها.
- تتذكر عن الناس اللي في الروم بس، وكل سيرفر له ذاكرته.
- الأمر `/forget` يمسح كل اللي تعرفه عن الناس والسيرفر (وكلام الشات اللي حفظته). `REMEMBER_PEOPLE=false` يطفيها.
- الذاكرة تنحفظ في مجلد `data`. على Railway بدون **Volume** تضيع مع كل نشر جديد: سوّ Volume على المسار `/app/data` وحط `RAILWAY_RUN_UID=0` في Variables.

**الأوامر**

| الأمر | وش يسوي |
|---|---|
| `/join` | يدش الروم الصوتي اللي أنت فيه |
| `/leave` | يطلع من الروم |
| `/ask` | تسأله كتابة، ويرد كتابة (وبصوت إذا هو في الروم) |
| `/mode` | يرد بس لما تناديه، أو على أي كلام |
| `/stop` | يسكت ويلغي الردود اللي بالانتظار |
| `/reset` | ينسى السالفة ويبدأ من جديد |
| `/forget` | ينسى اللي يعرفه عن الناس والسيرفر |

## الحدود المجانية (مهم)

- **الصوت هو أصغر حد مجاني**: Gemini عنده 3 موديلات صوت (`gemini-3.8-flash-tts` ← `gemini-3.8-flash-lite-tts` ← `gemini-3.1-flash-tts-preview`) وكل واحد حده اليومي صغير، وصوت Groq حده أصغر.
- **الحل الأقوى: صوت Azure الإماراتي (فاطمة)**: واضح وسريع، وعنده حد مجاني شهري كبير. حط `AZURE_SPEECH_KEY` و`AZURE_SPEECH_REGION` وتصير هي الصوت الأول تلقائياً، وGemini وGroq احتياط.
- **السمع**: Whisper في Groq حده 20 طلب بالدقيقة لكل موديل؛ إذا وصل، يكمل `whisper-large-v3`، وبعده Voxtral من Mistral (إذا فيه `MISTRAL_API_KEY`).
- **العقل**: Groq يحسب حجم الرد من حده بالدقيقة، فرد الصوت صغير (`MAX_REPLY_TOKENS=400`) والشات أكبر (`TEXT_MAX_REPLY_TOKENS=700`).
- تبي بدون حدود أبد؟ فعّل الدفع في Google AI Studio (رخيص للاستخدام الخفيف).

## السرعة

**⚡ Gemini Live:** الردود في الروم الصوتي تحاول تطلع من **Gemini Live**: السؤال يروح له نص، وصوتها يرجع وهو يتكون، يعني العقل والصوت خطوة وحدة بدل خطوتين. Whisper يظل يسمع ويعرف إذا الكلام لها.
- **تنبيه:** بالمفتاح المجاني Google غالباً يرفض Live («exceeded your current quota»). البوت يحس بهذا من أول محاولة، فيوقف Live 12 ساعة ويرد بالطريقة العادية بدون تأخير. إذا فعّلت الدفع في Google AI Studio يشتغل بروحه.
- الجلسة تنفتح أول ما تدش الروم، وكل 9 دقايق تتجدد وتكمل نفس السالفة.
- تتكلم بصوتها المصمم إذا Live قبله، وإلا بصوت `Zephyr`، وتقدر تدور في Google بروحها.
- إذا Live ما بدا يتكلم خلال 6 ثواني (`LIVE_FIRST_AUDIO_MS`) أو تعطل، ترد بالطريقة العادية (عقل، بعده صوت)، وLive يرتاح شوي.
- `LIVE_VOICE=false` يرجع الطريقة العادية.

- أول جملة تنطق بسرعة (الرد يتقطع لقطع، وأول قطعة قصيرة)، والباقي يتجهز وهي تتكلم.
- صوت Gemini يشتغل **بث مباشر**: تبدأ تنطق أول ما توصل أول قطعة صوت (`TTS_STREAM=true`).
- إذا Gemini تأخر أكثر من نص ثانية، يشتغل Groq معه وأول جواب يربح (`LLM_HEDGE_MS=500`)، والانتظار بعد ما تسكت قصير (`SILENCE_MS=500`).
- **صوت صاحي مب نعسان**: صوت Gemini مصمم حيوي ونشيط، وكل جملة تنطق بأسلوب سريع ومبتسم (`GEMINI_VOICE_STYLE`)، والسكتات قبل وبعد الكلام والوقفات الطويلة تنقص (`VOICE_TIGHT`، `VOICE_MAX_PAUSE_MS=280`)، فتبدا تتكلم أسرع. صوت Azure أسرع بـ 10% (`AZURE_RATE`).
- العقل الأول Gemini 3.5 Flash-Lite (يفكر أقل شي بروحه، فيرد بسرعة)، والتعليمات قصيرة عشان كل طلب أسرع وأرخص، والعبارات القصيرة مثل «ها حياتي» تنحفظ فتطلع فوراً.
- في الـ Logs تشوف سطر «🔊 الصوت جهز بعد X ثانية» — هذا الوقت الفعلي لكل رد.

| `FOLLOWUP_BIG_SECONDS` | `10` | في الروم الزحمة: اللي ردت عليه يقدر يسأل سؤال ثاني بدون اسمها خلال هالمدة |
| `STALE_SECONDS` | `40` | سؤال انتظر أكثر من كذا (كانت مشغولة) تتركه |
| `SALAM_COOLDOWN_SECONDS` | `600` | ترد «وعليكم السلام» على نفس الشخص مرة وحدة خلال هالمدة |
| `BOT_AVATAR_UPDATE` | `false` | `true` = يبدّل صورة البوت بـ `avatar.png` |
| `AUTO_JOIN_CHANNEL_ID` | فاضي | آيدي روم يدشه البوت تلقائياً ويبقى فيه |
| `CHAT_MESSAGES` | `false` | `true` = يكتب في شات الروم الصوتي (إعلان الدخول، السؤال والجواب، الأخطاء). الافتراضي: كل شي في الـ Logs بس |
| `POST_TRANSCRIPTS` | `true` | (يشتغل بس إذا `CHAT_MESSAGES=true`) يكتب السؤال والجواب |
| `WELCOME` | `true` | ترحب باسم اللي يدخل الروم |
| `WELCOME_REPLIES` | هلا والله {name},… | جمل الترحيب (افصل بينها بفاصلة، و`{name}` مكان الاسم) |
| `WELCOME_COOLDOWN_SECONDS` | `180` | ما ترحب بنفس الشخص مرتين خلال هالمدة |
| `LIVE_VOICE` / `LIVE_MODEL` | `true` / `gemini-3.8-live` | الرد بـ Gemini Live (إذا الموديل مب موجود، تختار أحدث موديل Live يقبله مفتاحك) |
| `LIVE_VOICE_NAME` / `LIVE_FIRST_AUDIO_MS` | `Zephyr` / `6000` | الصوت الجاهز إذا Live ما قبل صوتها المصمم / كم تنتظر أول صوت قبل الطريقة العادية |
| `BARGE_IN` | `false` | `true` = تسكت إذا أحد تكلم فوقها (الافتراضي: تكمل كلامها) |
| `BARGE_IN_MS` | `500` | كم لازم يتكلم (بالملي ثانية) عشان تسكت |
| `MOVE_BY_VOICE` | `true` | «فطوم روحي روم …» |
| `WEB_SEARCH` | `auto` | `auto` = تبحث بس للأسئلة الحديثة، `always`، أو `off` |
| `SEARCH_WORDS` | فاضي | كلمات زيادة تخليها تبحث |

كل الإعدادات مشروحة في `.env.example`. **شخصية البوت** (طريقة كلامه ولهجته) في ملف `prompt.txt`.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| أوامر `/` ما تطلع | أضف البوت مرة ثانية بالرابط اللي في الـ Logs، وسكّر ديسكورد وافتحه. |
| «الاتصال الصوتي ما اكتمل» | الاستضافة تمنع UDP. جرّب منطقة ثانية أو جهاز ثاني. خلي `DEBUG=true` للتفاصيل. |
| يدش بس ما يسمع | تأكد إنه مو **Server Deafen**، وشوف الـ Logs: لازم يطلع فيها كلامك 🗣️. |
| «خلص حد Gemini/Groq المجاني» | خلص الحد اليومي — يرجع بكرة، أو فعّل الدفع. |
| تكتب بس وما أسمع صوتها | غالباً خلص حد الصوت — شوف رسالة الشات والـ Logs. |
| يرد على كلام مو له | خله `REPLY_MODE=name` وقلّل `FOLLOWUP_SECONDS`. |
| خطأ 401 / 403 | المفتاح غلط — سو مفتاح جديد وحطه في Variables ثم Deploy. |

## الخصوصية

- البوت ما يكتب في شات الروم (كل شي في الـ Logs). خبّر ربعك إن البوت في الروم وإنه يسمع. إذا تبي يكتب، حط `CHAT_MESSAGES=true`.
- الشات العام: فطوم تقرا الرسائل في الروم المحدد بس، وتحفظ آخر 200 سطر منها (بدون روابط ولا أرقام طويلة) عشان تفهم الجو. `/forget` يمسحها، و`REMEMBER_PEOPLE=false` يطفي الحفظ.
- الصوت ما ينحفظ: يتحول لنص عند Groq، والنص يروح لـ Gemini عشان الرد والصوت (وإذا خلص حده، يروح لـ Groq).
